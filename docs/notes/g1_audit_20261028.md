## G1.12 (not built)

ft3 normalises each lane by its own causal running mean / sd (`_causal_stats`, std floor 1e-3) and then applies asinh. A
constant lane gives x - mu = 0 exactly, so z = 0 for 0.3, -0.7 and 5.0 alike (checked); a constant plus a small fixed
pattern keeps only the pattern. The static value never reaches the model.
