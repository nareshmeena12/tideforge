# tideforge

Data and generator lab for Fluxion-Tide: find what the synthetic training data is missing, fix it, and prove each fix
on a benchmark-free real dev set (~1B points, ~340 datasets) with a 5M softmax model.

- Plan and experiment index: [EXPERIMENTS.md](EXPERIMENTS.md)
- Dev-set collection: [DATA_COLLECTION.md](DATA_COLLECTION.md)
- Overview report: [docs/report/landscape.pdf](docs/report/landscape.pdf)
- Working rules (for people and for Claude Code): [CLAUDE.md](CLAUDE.md)

Code copied from the tidemark repo lives, unedited, in `third_party/tidemark_e21cbf0/`.
